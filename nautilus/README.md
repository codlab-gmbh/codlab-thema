# File (Nautilus) di CodLab Thema

*English: the CodLab pieces for GNOME Files (Nautilus) 51 on Fedora 45.*

| Cartella | Che cosa è |
|---|---|
| [`codlab`](codlab/) | la serie di otto patch per Nautilus 51.1, `serie.json` e lo spec della release `51.1-2.4.codlab` |
| [`integrazione`](integrazione/) | la ricostruzione automatica sopra ogni Nautilus di Fedora, il repo locale `codlab-repo`, le anteprime RAW e le colonne foto |
| [`vetro`](vetro/) | il vetro dentro File: un'estensione nautilus-python e due fogli di stile |

Qui non si pubblicano pacchetti binari: File si ricostruisce dal pacchetto sorgente di Fedora con la serie di patch.
